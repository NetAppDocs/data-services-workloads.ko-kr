= NetApp Workload Factory에서 자격 증명을 제거합니다.
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
더 이상 필요하지 않은 자격 증명은 Workload Factory에서 삭제할 수 있습니다. FSx for ONTAP 파일 시스템과 연결되지 않은 자격 증명만 삭제할 수 있습니다.

.단계
. link:https://console.netapp.com["NetApp Console"^]에 로그인하십시오.
. NetApp Console 메뉴에서 *워크로드* > *관리* > *자격 증명*을 선택합니다.
. *자격 증명* 페이지에서 다음을 수행하십시오:
+
** Workload Factory 콘솔에서 자격 증명 세트에 대한 작업 메뉴를 선택한 다음 *제거*를 선택합니다. *제거*를 선택하여 확인합니다.
** NetApp Console에서 자격 증명 세트의 작업 메뉴를 선택한 다음 *삭제*를 선택합니다. *삭제*를 선택하여 확인합니다.
