= Amazon EVS용 배포 계획을 수동으로 생성합니다
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload Factory에 로그인하여 VMware 계획 센터에 액세스하십시오. 여기에서 필요에 맞게 Amazon EVS용 배포 계획 또는 마이그레이션 계획을 수동으로 생성할 수 있습니다.

Amazon Elastic VMware Service에서 가상 머신에 대한 요구 사항을 수동으로 지정하고 사용자 지정 Amazon FSx for NetApp ONTAP 파일 시스템을 외부 데이터 저장소로 사용할 수 있습니다.



[[requirements]]
== 요구 사항

* Workload Factory에 액세스하려면 사용자 이름과 암호가 있어야 합니다. 액세스 권한이 없는 경우 지금 계정을 생성하십시오. 지침을 확인하십시오 link:quick-start-vmware.html["여기"].
* Amazon Elastic VMware Service 구독이 있어야 합니다.




[[steps]]
== 단계

. link:https://console.netapp.com["NetApp Console"^]에 로그인하십시오.
. 메뉴 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 Workload Factory의 메뉴 항목인 Workloads로 이동하는 데 사용됩니다."], *워크로드* > *VMware*를 선택합니다.
+
계획 센터가 표시됩니다.

. *EVS 계획을 수동으로 생성*을 선택합니다.
. VM 환경에 대한 요구 사항을 입력하십시오.
+
[NOTE]
====
다음 VM 마이그레이션 성능 요구 사항 및 권장 사항에 유의하십시오.

** 성능상의 이유로 VM 인벤토리에는 최소 10TiB의 스토리지 용량을 권장합니다.
** Amazon Elastic VMware Service 데이터스토어에는 최소 처리량이 필요하며, 이는 배포에 지정하는 필수 IOPS 수에 따라 달라집니다.
** FSx for ONTAP 파일 시스템 구성에 따라 Amazon Elastic VMware Service 환경이 최적의 성능을 발휘하려면 최소 개수의 외부 데이터스토어가 필요합니다.


====
. 준비가 되면 *계획 검토*를 선택하여 마이그레이션 계획을 검토하십시오.
. 계획을 검토하십시오. 각 섹션을 펼쳐서 계획의 세부 정보를 확인하십시오.
+
기본적으로 Workload Factory는 마이그레이션 계획을 계획 센터에 저장합니다. 페이지 상단 부근에서 이 옵션을 선택 해제할 수 있습니다.

. 선택적으로 페이지 오른쪽 상단의 *계획 관리*를 선택한 다음 *보고서 다운로드(.pdf)* 또는 *VM 스토리지 배포 다운로드(.csv)*를 선택하여 마이그레이션 계획을 PDF 또는 CSV 파일로 내보낼 수 있습니다.
+
.csv 파일은 마이그레이션 계획에 포함된 모든 VM과 할당된 스토리지 볼륨의 맵을 생성합니다.

. 배포 계획을 프로비저닝할 준비가 되면 *프로비저닝*을 선택하십시오.
