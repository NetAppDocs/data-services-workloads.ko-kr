= VMware 워크로드를 사용하여 VMware Cloud로 마이그레이션하기 전에 VM 구성을 캡처하세요.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
현재 VM 구성을 캡처하려면 마이그레이션 어드바이저 VM 수집 스크립트 또는 RVTools를 사용할 수 있습니다. 가장 정확한 계획을 수립하려면 VM 구성 및 성능 데이터를 모두 수집하는 마이그레이션 어드바이저 VM 수집 스크립트를 사용하는 것이 좋습니다.

[role="tabbed-block"]
====
.마이그레이션 어드바이저 VM 수집기 스크립트를 사용하십시오
--
NetApp 마이그레이션 어드바이저 VM 수집기 스크립트는 RVTools가 수집하는 것과 유사하게 사용자의 vCenter에서 VM 구성 정보를 수집하지만, 실제 읽기 및 쓰기 IOPS와 처리량 통계를 제공하기 위해 현재 VM 성능 데이터를 캡처합니다.

Codebox 창에서 Migration advisor VM collector 스크립트를 복사하려면 Migration advisor를 시작해야 합니다.

.시작하기 전에
수집기 스크립트를 실행할 시스템은 다음 요구 사항을 충족해야 합니다:

* Microsoft PowerShell 7.0 이상이 설치되어 있어야 합니다. PowerShell을 설치해야 하는 경우  https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell?view=powershell-7.4["Microsoft PowerShell 설명서"^]를 참조하십시오.
* VMware PowerCLI가 설치되어 있어야 합니다. PowerCLI를 설치해야 하는 경우  https://docs.vmware.com/en/VMware-vSphere/7.0/com.vmware.esxi.install.doc/GUID-F02D0C2D-B226-4908-9E5C-2E783D41FE2D.html["VMware PowerCLI 설명서"^]을(를) 참조하십시오.
* SSL 인증서 확인 기능을 비활성화해야 합니다.
* PowerShell은 서명되지 않은 스크립트 실행을 허용해야 합니다.


참고로, VM에서 장기적인 통계(일일 통계)를 수집하려면 vSphere 관리 콘솔(VMware 관리 환경)에서 통계 레벨 3 이상을 활성화해야 합니다.

.단계
. link:https://console.netapp.com["NetApp Console"^]에 로그인하십시오.
. 메뉴 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 Workload Factory의 메뉴 항목인 Workloads로 이동하는 데 사용됩니다."], *워크로드* > *VMware*를 선택합니다.
+
계획 센터가 표시됩니다.

. VMware 메뉴에서 *평가 및 계획*을 선택한 다음 *VMware Cloud on AWS로 마이그레이션*을 선택합니다.
+
VMware 마이그레이션 어드바이저의 기본 페이지가 표시됩니다.

. *계획 및 VMC 생성*을 선택합니다.
. *시작하기!*를 선택합니다. 체크박스를 선택하면 이 페이지가 다시 표시되지 않도록 설정할 수 있습니다.
. *새 배포 계획 생성*을 선택하고 *마이그레이션 어드바이저 VMware 데이터 수집기 사용* 옵션을 선택한 다음 *다음*을 선택합니다.
+
*VMware Cloud on AWS 마이그레이션 준비* 페이지가 표시됩니다.

. Codebox 창에서 image:button-download-codebox.png["다운로드 버튼"]을(를) 선택하여 Migration advisor VM 수집기 스크립트("list-vms.ps1")를 대상 시스템에 저장하거나, image:button-copy-codebox.png["복사 버튼"]을(를) 선택하여 스크립트를 복사하여 적절한 시스템에 붙여넣습니다.
. 현재 VM의 구성을 캡처하려면 다음 단계를 따르십시오:
+
.. 데이터 수집기를 다운로드했으며 PowerShell 및 PowerCLI가 설치된 시스템에 로그인하십시오.
.. 다음 명령어를 실행하여 VMware vCenter 서버에 연결하십시오:
+
[source, console]
----
Connect-VIServer -server <server_IP>
----
+
<server_IP>을(를) VMware 서버의 IP 주소 또는 호스트 이름으로 바꾸십시오.

.. 다운로드한 데이터 수집기 스크립트를 실행하고 "일별" 또는 "시간별" VM 통계에 대한 데이터 수집 옵션을 지정하십시오.
+
[source, console]
----
./list-vms.ps1 -isLongTermDataCollectionEnabled <true | false>
----
+
여기서:

+
*** *true*는 지난 24시간 동안의 IOPS 및 처리량 데이터를 5분 간격으로 수집합니다
*** *false*는 지난 1시간 동안의 IOPS 및 처리량 데이터를 20초 간격으로 수집합니다.






.결과
이 스크립트는 현재 작업 디렉터리에 이름이  `list-vms-yyyy-MM-dd-HH-mm-ss.csv`인 CSV 파일을 출력합니다. CSV 파일에는 모든 가상 머신(VM) 목록과 해당 속성, 그리고 IOPS 및 처리량 데이터가 포함되어 있습니다.

--
.RVTools 소프트웨어를 사용하십시오
--
RVTools는 VCenter 및 ESX 서버(5.x~8.0)와 상호 작용하여 VMware 가상 환경에 대한 정보를 수집하는 Windows 애플리케이션입니다. VM, CPU, 메모리, 디스크, 클러스터, ESX 호스트, 데이터스토어 등에 대한 정보를 수집합니다. 이 정보를 xlsx 파일로 내보내 마이그레이션 어드바이저에서 사용할 수 있습니다.

link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["RVTools에 대해 자세히 알아보세요"^]

.단계
. link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["RVTools 웹사이트"^]에 RVTools 4.4.2 이상을 다운로드하여 설치하십시오.
. RVTools를 실행하고 대상 VCenter 서버에 로그인합니다.
+
이렇게 하면 해당 VCenter Server에 대한 정보를 수집합니다.

. VMware 정보를 xlsx 또는 xls 파일로 내보내십시오.
+
자세한 내용은 link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["리소스 섹션의 RVTools 설명서"^]의 "명령줄 매개변수" 장을 참조하십시오.



.결과
결과가 담긴 xlsx 또는 xls 파일이 작업 디렉토리에 저장됩니다.
