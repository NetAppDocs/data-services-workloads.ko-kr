= VM 인벤토리 데이터를 NetApp Workload Factory에 업로드합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
마이그레이션 계획을 생성하기 전에 VM 인벤토리 데이터를 업로드해야 합니다.

.단계
. link:https://console.netapp.com["NetApp Console"^]에 로그인하십시오.
. 메뉴 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 Workload Factory의 메뉴 항목인 Workloads로 이동하는 데 사용됩니다."], *워크로드* > *VMware*를 선택합니다.
+
계획 센터가 표시됩니다. 계획 센터에서 VM 인벤토리 데이터를 업로드하고, 이전에 업로드한 인벤토리 데이터를 확인하고, VM 인벤토리 데이터 세트를 사용하여 마이그레이션을 계획할 수 있습니다.

. *VM 인벤토리 업로드*를 선택하십시오.
. 사용할 데이터 수집 방법을 선택하십시오:


[role="tabbed-block"]
====
.RVTools(빠른 평가) 사용
--
RVTools는 VCenter 및 ESX 서버(5.x~8.0)와 상호 작용하여 VMware 가상 환경에 대한 정보를 수집하는 Windows 애플리케이션입니다. VM, CPU, 메모리, 디스크, 클러스터, ESX 호스트, 데이터스토어 등에 대한 정보를 수집합니다. 이 정보를 xlsx 파일로 내보내 마이그레이션 어드바이저에서 사용할 수 있습니다.

link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["RVTools에 대해 자세히 알아보세요"^]

.단계
. *RVTools* 타일을 선택하고 *다음*을 선택합니다.
+
*AWS 클라우드 온보딩 준비* 페이지가 표시됩니다.

. 생성할 VM 인벤토리 데이터 세트의 이름을 입력하십시오.
. link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["RVTools 웹사이트"^]에서 RVTools 4.4.2 이상을 다운로드하여 설치하십시오.
. RVTools를 실행하고 대상 VCenter 서버에 로그인합니다.
+
이렇게 하면 해당 VCenter Server에 대한 정보를 수집합니다.

. VMware 정보를 xlsx 또는 xls 파일로 내보내십시오.
+
자세한 내용은 link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["리소스 섹션에 있는 RVTools 문서"^]의 "명령줄 매개변수" 장을 참조하십시오.

. image:button-upload-file.png["업로드 버튼"]을(를) 선택하고 내보낸 RVTools 파일을 선택합니다.
. *업로드*를 선택합니다.
. *완료*를 선택합니다.


--
.데이터 수집기(상세 계획)를 사용하세요
--
NetApp 마이그레이션 어드바이저 VM 수집기 스크립트는 RVTools가 수집하는 것과 유사하게 vCenter에서 VM 구성 정보를 수집하지만, 실제 읽기 및 쓰기 IOPS와 처리량 통계를 제공하기 위해 현재 VM 성능 데이터를 캡처합니다. 이 스크립트는 다음 두 가지 모드 중 하나로 사용할 수 있습니다.

* 시간별 데이터 수집
* 일일 데이터 수집


Codebox 창에서 Migration advisor VM collector 스크립트를 복사하려면 Migration advisor를 시작해야 합니다.

.시작하기 전에
수집기 스크립트를 실행할 시스템은 다음 요구 사항을 충족해야 합니다:

* Microsoft PowerShell 7.0 이상이 설치되어 있어야 합니다. PowerShell을 설치해야 하는 경우  https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell?view=powershell-7.4["Microsoft PowerShell 설명서"^]를 참조하십시오.
* VMware PowerCLI가 설치되어 있어야 합니다. PowerCLI를 설치해야 하는 경우  https://docs.vmware.com/en/VMware-vSphere/7.0/com.vmware.esxi.install.doc/GUID-F02D0C2D-B226-4908-9E5C-2E783D41FE2D.html["VMware PowerCLI 설명서"^]을(를) 참조하십시오.
* SSL 인증서 확인 기능을 비활성화해야 합니다.
* PowerShell은 서명되지 않은 스크립트 실행을 허용해야 합니다.


참고로, VM에서 장기적인 통계(일일 통계)를 수집하려면 vSphere 관리 콘솔(VMware 관리 환경)에서 통계 레벨 3 이상을 활성화해야 합니다.

.단계
. *데이터 수집기* 타일을 선택하고 *다음*을 선택합니다.
+
Codebox 창이 페이지 오른쪽에 나타납니다.

. Codebox 창에서 image:button-download-codebox.png["다운로드 버튼"]을(를) 선택하여 Migration advisor 데이터 수집기 스크립트("list-vms.ps1")를 대상 시스템에 저장하거나, image:button-copy-codebox.png["복사 버튼"]을(를) 선택하여 스크립트를 복사한 다음 적절한 시스템에 붙여넣습니다.
. 현재 VM의 구성을 캡처하려면 다음 단계를 따르십시오:
+
.. 데이터 수집기를 다운로드했으며 PowerShell 및 PowerCLI가 설치된 시스템에 로그인하십시오.
.. 다음 명령어를 실행하여 VMware vCenter 서버에 연결하십시오:
+
[source, console]
----
Connect-VIServer -server <server_IP>
----
+
<server_IP>을(를) VMware 서버의 IP 주소 또는 호스트 이름으로 바꾸십시오.

.. 다운로드한 데이터 수집 스크립트를 실행하고 "시간별" 또는 "일별" VM 통계에 대한 데이터 수집 옵션을 지정하십시오.
+
[source, console]
----
./list-vms.ps1 -PerformanceStatisticsTimePeriod <LastHour | LastDay>
----
+
여기서:

+
*** *LastHour*는 지난 1시간 동안의 IOPS 및 처리량 데이터를 20초 간격으로 수집합니다.
*** *LastDay*는 지난 24시간 동안의 IOPS 및 처리량 데이터를 5분 간격으로 수집합니다.




+
선택적으로 옵션을 지정하지 않고 데이터 수집 스크립트를 실행할 수 있습니다. 이렇게 하면 대화형 메뉴에서 데이터 수집 기간을 선택할 수 있습니다.

+
+ 이 스크립트는 현재 작업 디렉터리에 이름에 타임스탬프가 포함된 압축 파일을 생성합니다. .zip 파일에는 모든 가상 머신(VM) 목록과 해당 속성, 그리고 IOPS 및 처리량 데이터가 포함되어 있습니다.

. *업로드*를 선택합니다.


--
.NetApp Data Infrastructure Insights(상세 계획)를 사용하십시오.
--
NetApp Data Infrastructure Insights는 클라우드 인프라 모니터링 툴로, 전체 인프라에 대한 가시성을 제공합니다. 마이그레이션 어드바이저가 VMware 인프라에 대한 정보를 수집할 수 있도록 마이그레이션 어드바이저와 Data Infrastructure Insights 간의 임시 API 통신을 활성화해야 합니다.

https://docs.netapp.com/us-en/data-infrastructure-insights/["Data Infrastructure Insights에 대해 자세히 알아보기"^]

.단계
. *Data Infrastructure Insights* 타일을 선택하고 *다음*을 선택합니다.
+
*AWS 클라우드 온보딩 준비* 페이지가 표시됩니다.

. 생성할 VM 인벤토리 데이터 세트의 이름을 입력하십시오.
. Data Infrastructure Insights의 테넌트 엔드포인트를 입력하십시오.
+
이것은 Data Infrastructure Insights에 액세스하는 데 사용하는 URL이어야 합니다.

. 아직 Data Infrastructure Insights용 API 액세스 토큰을 생성하지 않은 경우, 해당 페이지의 안내에 따라 생성하십시오. 그렇지 않은 경우, *API 액세스 토큰 입력* 텍스트 상자에 API 액세스 토큰을 붙여넣으십시오.
. *업로드*를 선택합니다.
+
Workload Factory는 Data Infrastructure Insights에서 정보를 수집합니다.
