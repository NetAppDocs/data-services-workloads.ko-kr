= 권장되는 FSx for ONTAP 파일 시스템을 배포하십시오.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
권장되는 FSx for ONTAP 파일 시스템(경우에 따라 여러 파일 시스템)이 요구 사항을 정확히 충족하는지 확인한 후 Workload Factory를 사용하여 AWS 환경에 시스템을 배포할 수 있습니다.

Workload Factory에서 권장하는 구성에 따라 FSx for ONTAP 파일 시스템을 배포하려면 link:../fsx-storage/create-discover-systems.html["NetApp Workload Factory에서 FSx for ONTAP 파일 시스템을 생성합니다."^]의 지침을 따르십시오. 지침의 *고급 생성* 단계를 사용하여 파일 시스템을 완벽하게 사용자 지정할 수 있습니다.
