= NetApp Workload Factory for Databases에서 샌드박스 복제본을 생성합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload Factory for Databases에서 데이터베이스의 샌드박스 복제본을 생성하면 원본 데이터베이스를 변경하지 않고도 개발, 테스트, 통합, 분석, 교육, QA 등에 복제본을 사용할 수 있습니다.

.이 작업 정보
샌드박스 클론은 소스 데이터베이스의 최신 스냅샷을 기반으로 생성됩니다. 이 클론은 소스 데이터베이스와 동일한 Microsoft SQL Server에 생성될 수도 있고, 동일한 FSx for ONTAP 파일 시스템을 공유하는 다른 Microsoft SQL Server에 생성될 수도 있습니다.

.시작하기 전에
샌드박스 복제본을 생성하기 전에 다음 필수 조건을 모두 충족했는지 확인하십시오.

* *자격 증명 및 권한*: Workload Factory에서 샌드박스 복제본을 생성하려면 link:../fsx-storage/add-credentials.html["AWS 계정 자격 증명 및 _작업 및 복구_ 권한"^]이(가) 있어야 합니다.
+
또는 Codebox를 사용하여 부분적으로 완성된 템플릿을 복사하거나 완성된 템플릿을 생성하여 REST API를 통해 Workload Factory 외부에서 샌드박스 복제본을 생성할 수 있습니다. link:../admin/codebox-automation.html["Codebox 자동화에 대해 자세히 알아보세요"^].

* *Microsoft SQL Server*: 새 샌드박스 복제본을 호스팅하려면 Workload Factory for Databases에 관리형 Microsoft SQL Server가 있어야 합니다.
* *AWS Systems Manager*: AWS Systems Manager를 통해 Microsoft SQL 호스트에서  `NT Authority\SYSTEM` 사용자 권한이 활성화되어 있는지 확인하십시오.
* *원본 데이터베이스*: 클론을 생성하려면 원본 데이터베이스가 필요합니다.


.단계
. link:https://console.netapp.com["NetApp Console"^]에 로그인하십시오.
. 메뉴 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 Workload Factory의 메뉴 항목인 Workloads로 이동하는 데 사용됩니다."], *워크로드* > *데이터베이스*를 선택합니다.
. 데이터베이스에서 *샌드박스* 탭을 선택하십시오.
. 샌드박스 탭에서 *새 샌드박스 만들기*를 선택합니다.
. 새 샌드박스 생성 페이지의 데이터베이스 소스 항목에 다음을 입력하십시오.
+
.. *원본 데이터베이스 호스트*: 원본 데이터베이스 호스트를 선택하십시오.
.. *원본 데이터베이스 인스턴스*: 원본 데이터베이스 인스턴스를 선택하십시오.
.. *원본 데이터베이스*: 복제할 원본 데이터베이스를 선택하십시오.


. 데이터베이스 대상 항목에 다음 정보를 입력하십시오.
+
.. *대상 데이터베이스 호스트*: 소스 호스트와 동일한 VPC에 있고 동일한 FSx for ONTAP 파일 시스템을 사용하는 샌드박스 클론용 대상 데이터베이스 호스트를 선택합니다.
.. *대상 데이터베이스 인스턴스*: 샌드박스 복제에 사용할 대상 데이터베이스 인스턴스를 선택합니다.
.. *대상 데이터베이스*: 샌드박스 복제본의 이름을 입력하세요.


. *마운트*: 데이터 파일 및/또는 로그 파일이 여러 개인 SQL 데이터베이스를 복제할 때 Workload Factory는 자동 할당되거나 정의된 드라이브 문자 아래의 모든 파일을 복제합니다.
+
다음 옵션 중 하나를 선택하십시오.

+
.. *마운트 포인트 자동 할당*
.. *마운트 지점 경로 정의*
+
마운트 지점 경로를 정의하려면 다음을 제공하십시오:

+
*** 데이터 파일 경로에 사용할 드라이브 문자를 입력하십시오.
*** 로그 파일 경로에 사용할 드라이브 문자를 입력하십시오.




. *태그 정의*: 샌드박스 복제본을 정의할 태그를 선택하세요.
. *Create*를 클릭합니다.


작업 진행 상황을 확인하려면 *작업 모니터링* 탭으로 이동하십시오.
