= NetApp Workload Factory에서 볼륨 복제
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload Factory에서 볼륨을 클론하여 테스트를 위한 원본 볼륨의 읽기/쓰기 볼륨을 만듭니다.

클론은 현재 시점의 데이터 상태를 반영합니다. 또한 클론을 사용하여 추가 사용자에게 운영 데이터에 대한 액세스 권한을 부여하지 않고도 데이터에 액세스하도록 할 수 있습니다.

.이 작업 정보
볼륨 클론은 FlexClone 볼륨에서만 지원됩니다.

볼륨이 복제되면 상위 볼륨의 스냅샷을 참조하는 쓰기 가능한 볼륨이 생성됩니다. 클론 생성은 몇 초 만에 완료됩니다. 복제된 데이터는 볼륨 클론에 저장되지 않고 상위 볼륨에 저장됩니다. 클론 생성 후 볼륨에 새로 기록되는 모든 데이터는 클론에 저장됩니다.

클론된 볼륨에 상위 볼륨의 모든 데이터와 생성 후 클론에 추가된 새 데이터가 포함되도록 하려면 상위 볼륨에서 link:split-cloned-volume.html["클론 분할"] 해야 합니다. 또한 클론이 있는 상위 볼륨은 삭제할 수 없습니다. 상위 볼륨을 삭제하려면 먼저 클론을 분할해야 합니다.

.단계
. link:https://console.netapp.com["NetApp Console"^]에 로그인하십시오.
. 메뉴 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 Workload Factory의 메뉴 항목인 Workloads로 이동하는 데 사용됩니다."], *워크로드* > *볼륨 탐색기*를 선택합니다.
. 복제할 볼륨의 작업 메뉴를 선택합니다.
. *데이터 보호 작업*을 선택한 다음 *볼륨 클론*을 선택합니다.
. 볼륨 클론 대화 상자에서 볼륨 클론의 이름을 입력합니다.
. *Clone*을 선택합니다.
