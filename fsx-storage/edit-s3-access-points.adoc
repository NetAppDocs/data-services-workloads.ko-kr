= NetApp Console에서 FSx for ONTAP 볼륨의 S3 액세스 포인트를 편집합니다.
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Console에서 FSx for ONTAP 볼륨의 S3 액세스 포인트 세부 정보를 업데이트하고 태그를 관리합니다.

액세스 포인트에 대한 *인벤토리 테이블*을 활성화 또는 비활성화할 수도 있습니다. 인벤토리 테이블은 S3 액세스 포인트에서 접근 가능한 모든 객체에 대한 메타데이터를 생성하며, 이 과정에서 AWS S3 요청 비용이 발생합니다. 자세한 내용은 link:https://aws.amazon.com/s3/pricing/["Amazon S3 가격 책정 문서"^]을 참조하십시오.

.단계
. link:https://console.netapp.com["NetApp Console"^]에 로그인하십시오.
. 메뉴 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 Workload Factory의 메뉴 항목인 Workloads로 이동하는 데 사용됩니다."], *워크로드* > *볼륨 탐색기*를 선택합니다.
. S3 액세스 포인트를 편집하려는 볼륨의 작업 메뉴를 선택한 다음 *고급 작업*을 선택하고 *S3 액세스 포인트 관리*를 선택합니다.
. *S3 액세스 포인트 관리* 화면에서 작업 메뉴를 선택한 다음 *액세스 포인트 편집*을 선택합니다.
. 업데이트한 후 *적용*을 선택합니다.
+
저널 테이블 기능에 필요한 인프라를 설정하려면 S3 액세스 포인트의 네트워크 구성으로 *인터넷*을 선택해야 합니다. link:setup-journal-table.html["저널 테이블 인프라를 설정하는 방법을 알아보세요"].
