= NetApp Workload Factory에서 스토리지 VM 설정을 관리합니다.

:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload Factory에서 스토리지 VM의 설정을 관리합니다. 스토리지 VM에 대한 Active Directory를 구성 및 업데이트하고, 스토리지 VM 암호를 업데이트하고, 스토리지 VM에 대한 태그를 관리할 수 있습니다.



[[configure-and-update-ad-for-a-storage-vm-in-netapp-workload-factory]]
== NetApp Workload Factory에서 스토리지 VM에 대한 AD 구성 및 업데이트

NetApp Workload Factory의 FSx for ONTAP 파일 시스템에 있는 스토리지 VM에 대한 Active Directory를 구성하고 업데이트합니다.

스토리지 VM의 Active Directory를 구성하고 업데이트하는 데에도 동일한 단계가 적용됩니다.

.단계
. link:https://console.netapp.com["NetApp Console"^]에 로그인하십시오.
. 메뉴 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 Workload Factory의 메뉴 항목인 Workloads로 이동하는 데 사용됩니다."], *워크로드* > *스토리지* > *FSx for ONTAP*을 선택합니다.
. *FSx for ONTAP*에서 업데이트할 스토리지 VM이 있는 파일 시스템의 작업 메뉴를 선택한 다음 *관리*를 선택합니다.
. 스토리지 VM 아래의 파일 시스템 개요에서 *관리*를 선택합니다.
. 스토리지 VM 관리 화면에서 Active Directory를 구성할 스토리지 VM의 작업 메뉴를 선택한 다음 *기본 작업* > *AD 구성 관리*를 선택합니다.
. AD 구성 관리 페이지에서 다음을 제공하십시오:
+
.. *가입할 Active Directory 도메인*: Active Directory의 정규화된 도메인 이름(FQDN)을 입력하십시오.
.. *DNS IP 주소*: 쉼표로 구분하여 최대 3개의 IP 주소를 입력하십시오.
.. *SMB 서버 NetBIOS 이름*: 스토리지 VM용으로 생성할 Active Directory 컴퓨터 오브젝트의 SMB 서버 NetBIOS 이름을 입력하십시오. 이는 Active Directory에서 해당 SVM의 이름입니다.
.. *사용자 이름*: 기존 Active Directory에 있는 서비스 계정의 사용자 이름을 입력하십시오.
+
도메인 접두사나 접미사를 포함하지 마십시오.  `EXAMPLE\ADMIN`의 경우  `ADMIN`를 사용하십시오.

.. *비밀번호*: 서비스 계정의 비밀번호를 입력하세요.
.. *조직 단위(OU)*: 조직 단위를 입력하십시오.
+
OU는 파일 시스템을 연결하려는 조직 단위의 고유 경로 이름입니다.

.. *위임된 관리자 그룹*: 선택적으로 위임된 파일 시스템 관리자 그룹을 입력합니다.
+
위임된 관리자 그룹은 Active Directory에서 파일 시스템을 관리할 수 있는 그룹의 이름입니다.

+
AWS Managed Microsoft AD를 사용하는 경우, AWS Delegated FSx Administrators, AWS Delegated Administrators 또는 OU에 대한 위임 권한이 있는 사용자 지정 그룹 등의 그룹을 지정해야 합니다.

+
자체 관리형 AD에 연결하는 경우 AD의 그룹 이름을 사용하십시오. 기본 그룹은  `Domain Admins`입니다.



. *적용*을 선택합니다.




[[manage-storage-vm-tags]]
== 스토리지 VM 태그 관리

태그를 사용하면 리소스를 분류할 수 있습니다. NetApp Workload Factory에서는 언제든지 스토리지 VM에 태그를 추가, 편집 및 삭제할 수 있습니다.

.단계
. link:https://console.netapp.com["NetApp Console"^]에 로그인하십시오.
. 메뉴 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 Workload Factory의 메뉴 항목인 Workloads로 이동하는 데 사용됩니다."], *워크로드* > *스토리지* > *FSx for ONTAP*을 선택합니다.
. *FSx for ONTAP*에서 업데이트할 스토리지 VM이 있는 파일 시스템의 작업 메뉴를 선택한 다음 *관리*를 선택합니다.
. 스토리지 VM 아래의 파일 시스템 개요에서 *관리*를 선택합니다.
. 스토리지 VM 관리 화면에서 태그를 편집할 스토리지 VM의 작업 메뉴를 선택한 다음 *기본 작업* > *스토리지 VM 태그 편집*을 선택합니다.
. 스토리지 VM 태그 편집 페이지에서 태그를 추가, 편집 또는 제거합니다.
+
스토리지 VM에 적용할 수 있는 최대 태그 수는 50개입니다.

. *적용*을 선택합니다.




[[reset-the-storage-vm-password-in-netapp-workload-factory]]
== NetApp Workload Factory에서 스토리지 VM 암호를 재설정합니다.

필요한 경우 NetApp Workload Factory에서 스토리지 VM의 암호를 재설정하십시오.

.단계
. link:https://console.netapp.com["NetApp Console"^]에 로그인하십시오.
. 메뉴 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 Workload Factory의 메뉴 항목인 Workloads로 이동하는 데 사용됩니다."], *워크로드* > *스토리지* > *FSx for ONTAP*을 선택합니다.
. *FSx for ONTAP*에서 스토리지 VM 암호를 재설정할 파일 시스템의 작업 메뉴를 선택한 다음 *관리*를 선택합니다.
. 스토리지 VM 아래의 파일 시스템 개요에서 *관리*를 선택합니다.
. 스토리지 VM 관리 화면에서 암호를 재설정할 스토리지 VM의 작업 메뉴를 선택한 다음 *기본 작업* > *암호 재설정*을 선택합니다.
. 암호 재설정 대화 상자에서 다음 정보를 입력하십시오:
+
.. *새 암호*: 스토리지 VM에 사용할 새 암호를 입력하십시오.
.. *비밀번호 확인*: 새 비밀번호를 다시 입력하여 확인하세요.
