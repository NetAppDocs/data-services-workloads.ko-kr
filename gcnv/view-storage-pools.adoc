= NetApp Workload Factory에서 Google Cloud NetApp Volumes 스토리지 풀 보기
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload Factory에서 Google Cloud NetApp Volumes 스토리지 풀과 해당 세부 정보를 확인하십시오.

.단계
. link:https://console.netapp.com["NetApp Console"^]에 로그인하십시오.
. 메뉴 image:workloads-menu-icon.png["햄버거 메뉴 아이콘은 Workload Factory의 메뉴 항목인 Workloads로 이동하는 데 사용됩니다."], *스토리지* > *Google Cloud NetApp Volumes*를 선택합니다.
. *프로젝트*, *자격 증명*, *지역* 필터를 사용하여 표시되는 스토리지 풀의 범위를 지정하십시오.
. 이름, 상태, 서비스 수준, 용량 등의 세부 정보가 표시되는 스토리지 풀 테이블을 검토하십시오.
+
스토리지 풀의 서비스 수준은 Standard, Premium, Extreme, Flex File 또는 Flex Unified입니다. 모드는 Flex Unified 스토리지 풀의 경우 Default 또는 ONTAP으로 표시되고, 다른 모든 서비스 수준의 경우 Default로 표시됩니다.

. 스토리지 풀의 이름을 선택하여 처리량 및 설명 등 세부 정보를 엽니다.
