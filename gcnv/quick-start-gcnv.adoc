= Google Cloud NetApp Volumes 빠른 시작
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Google Cloud NetApp Volumes를 시작하려면 Google Cloud를 설정한 다음 시스템을 생성하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["하나"] link:set-up.html["Google Cloud NetApp Volumes 설정"]
[role="quick-margin-para"]
Google에서 서비스 계정을 생성하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["둘"] link:add-roles.html["역할 할당"]
[role="quick-margin-para"]
Google Cloud NetApp Volumes 사용을 시작하려면 적절한 권한이 있어야 하며, Google Cloud NetApp Volumes 관리자 또는 Google Cloud NetApp 뷰어 역할이 할당되어 있어야 합니다.

[role="quick-margin-para"]
image:role_gcnv.png["Google Cloud NetApp Volumes 역할의 스크린샷입니다."]

[role="quick-margin-para"]
NetApp Console에서 멤버에게 올바른 역할을 할당하십시오.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["3"] link:create-discover-systems.html["시스템 추가"]
[role="quick-margin-para"]
NetApp Console에서 *시스템 추가*를 클릭한 다음 *Google Cloud Platform*, *Google Cloud NetApp Volumes*, 그리고 *검색*을 차례로 클릭합니다. 서비스 계정과 Google Cloud 프로젝트에 대한 세부 정보를 입력합니다.
