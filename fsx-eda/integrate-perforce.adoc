= EDA용 Workload Factory를 Perforce와 통합
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
EDA를 Perforce Helix Visual Client (P4V)와 통합하여 개발자가 Perforce CLI를 사용하여 워크스페이스를 관리할 수 있도록 하십시오. 이를 통해 개발자는 프로젝트와 워크스페이스 간에 빠르게 전환할 수 있어 개발 시간을 절약할 수 있습니다.

.단계
.  https://builders.console.workloads.netapp.com/p4v["P4V 통합 파일"^]을(를) 다운로드하십시오.
. P4V를 열고 *툴* > *툴 관리* > *HTML 탭*으로 이동합니다.
. *HTML 탭 가져오기*를 선택하세요.
. P4V 통합 XML 파일을 선택하고 *가져오기*를 선택합니다.
. *보기* > *Workload Factory*로 이동합니다.


.결과
NetApp Workload Factory for EDA 웹 UI는 P4V 클라이언트 내에서 HTML 탭으로 나타납니다.
